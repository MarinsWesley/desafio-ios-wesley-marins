Heróis Marvel
Aplicativo iOS desenvolvido em Swift como projeto de estudo e prática de desenvolvimento iOS.
O projeto foi originalmente desenvolvido em 2022 e posteriormente atualizado e modernizado para atender aos requisitos do iOS 27 e Xcode 27, incluindo a atualização das dependências e a substituição da API originalmente utilizada.
🛠️ Tecnologias
- Swift
- UIKit
- Xcode 27
- iOS 27
- Alamofire
- Kingfisher
- CocoaPods
- WKWebView
- Codable

📱 Funcionalidades
- Pesquisa de super-heróis
- Listagem de personagens
- Exibição de imagens
- Exibição de atributos de poder
- Visualização de informações adicionais
- Tratamento de dados não informados pela API

🔄 Atualização do projeto
- Projeto originalmente desenvolvido como desafio de estudo e posteriormente atualizado para:
- Compatibilidade com iOS 27
- Compatibilidade com Xcode 27
- Atualização das dependências
- Migração da Marvel API para a Superhero API
- Adequação do projeto às versões atuais do Swift e UIKit
- Correção de problemas de compatibilidade e execução
